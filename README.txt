Hi! The movie properties are simple, with a title and genre being listed, as well as a Boolean for whether or not it's been watched (and the two buttons that go along with the visual card). Saving works by adding an item to localStorage from the movies HTML list by making the JSON object a string, and loading works by taking those strings and turning them back into usable JSONS to display on the HTML list
